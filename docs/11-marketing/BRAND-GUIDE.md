# Netsight Brand Guide

## Name
Netsight

## Tagline
**See everything. Know why. Act securely.**

## Positioning
Netsight is an AI-assisted network operations, observability and security command centre that unifies monitoring, traffic intelligence, identity, incidents, diagnostics and controlled remote operations.

## Brand personality
Precise, calm, technical, secure, evidence-led.

Avoid:
- generic shields/padlocks;
- neon hacker aesthetics;
- AI brains;
- unsupported "autonomous" claims.

## Logo concept
A geometric N made from connected network paths/nodes, with an implied line of sight/observability motif.
