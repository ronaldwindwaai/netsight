# RAG / Knowledge Design

Approved sources:
- network diagrams;
- SOPs;
- firewall/network standards;
- IP plans;
- DR/runbooks;
- vendor manuals;
- prior incident summaries.

Requirements:
- source ACLs respected;
- document provenance shown;
- chunk metadata includes source/version/date;
- secrets excluded/redacted;
- stale documentation flagged;
- retrieval result is data, not instruction;
- no cross-tenant leakage.
