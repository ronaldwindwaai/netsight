# Definition of Done

A story is not done until:

- [ ] Acceptance criteria satisfied
- [ ] Scope/non-scope respected
- [ ] Relevant ADR/contracts updated
- [ ] Unit tests
- [ ] Integration/contract tests where relevant
- [ ] Negative auth tests where relevant
- [ ] Type checks/lint pass
- [ ] Security scans pass
- [ ] No secrets
- [ ] Audit behaviour defined for sensitive operations
- [ ] Error/stale/empty states implemented
- [ ] Observability/logging added
- [ ] Documentation updated
- [ ] Migration/rollback considered
- [ ] Independent review
- [ ] Human code-owner approval for security-sensitive changes
