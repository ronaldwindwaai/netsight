# Privacy and Data Retention

Netsight can expose sensitive operational metadata such as:
- usernames;
- device ownership;
- domains/services accessed;
- IP/MAC history;
- security events;
- login times.

Principles:
- purpose limitation;
- least privilege;
- access auditing;
- configurable retention;
- aggregation for management;
- masking where detail is unnecessary;
- documented legal/HR/privacy policy before broad user surveillance features.

Retention classes should be configured separately:
- metrics;
- flow records;
- security events;
- incidents;
- audits;
- configurations;
- reports;
- identity history.
