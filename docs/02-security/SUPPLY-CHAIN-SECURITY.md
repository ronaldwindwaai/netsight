# Software Supply Chain Security

Required:
- lockfiles committed after initial compatibility resolution;
- dependency review;
- automated vulnerability scanning;
- secret scanning;
- SAST;
- container scanning;
- SBOM on release;
- minimal base images;
- versioned/reproducible builds where practical;
- provenance/signing where supported;
- dependency licence review.

LLM agents must justify new dependencies and prefer existing capabilities.
