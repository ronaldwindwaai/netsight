# Non-goals

MVP will not:
- replace firewalls, EDR or antivirus;
- decrypt all encrypted web traffic;
- become a packet-capture forensic platform;
- provide unrestricted autonomous remediation;
- build SNMP/NetFlow/SIEM engines from scratch;
- expose internal monitoring products directly as the primary user experience;
- claim user identity from IP address alone;
- make AI conclusions without evidence.
