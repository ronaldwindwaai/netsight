# Contributing to Netsight

1. Work from an issue with acceptance criteria.
2. Use a short-lived branch.
3. Do not push directly to protected branches.
4. Add/update tests with code.
5. Add an ADR when changing architecture.
6. Update API/data contracts before or with implementation.
7. Complete the PR security checklist.
8. Obtain required code-owner review.
9. Do not merge when required checks fail.
10. Never commit secrets.

See `docs/10-project-management/DEFINITION-OF-DONE.md`.
